# Daftar Tugas Pemrograman Berorientasi Objek (OOP) Dart

List tugas saya dari fork dart-oop pak khanif

## 1. Challenge: Class & Object

- [x] **Tugas Rumah:**
  - Buatlah class `Rumah` dengan properti `nama`, `alamat`, dan `jumlahKamar`.
  - Buatlah method `display()` untuk mencetak nilai dari ketiga properti tersebut.
  - Buatlah Object dari class `Rumah`, atur nilainya, dan panggil method `display()`.

## 2. Tugas Latihan 1: Constructor & Variasi Class

- [x] **Latihan 1.1 (Basic Class & Object):** Buat class `Mobil` (merk, model, tahun), buat objeknya, inisialisasi, dan cetak informasinya.
- [x] **Latihan 1.2 (Default Values):** Buat class `Mahasiswa` (nama, nim) dengan nilai default. Buat objek tanpa memberikan nilai tambahan dan cetak informasinya.
- [ ] **Latihan 1.3 (Parameterized Constructor):** Buat class `Buku` (judul, pengarang) menggunakan parameterized constructor. Buat objeknya dan cetak informasinya.
- [ ] **Latihan 1.4 (Named Constructor):** Buat class `Segitiga` (alas, tinggi, jenis) dengan named constructor berdasarkan jenisnya. Buat objeknya dan cetak informasinya.
- [ ] **Latihan 1.5 (Constant Constructor):** Buat class `Warna` (red, green, blue) dengan constant constructor. Buat beberapa objek konstan dan cetak informasinya.

## 3. Tugas Latihan 2: Encapsulation, Inheritance, Polymorphism, & Abstraction

- [ ] **Latihan 2.1 (Inheritance):** Buat class induk `Hewan` (nama, suara()) dan class anak `Kucing` (jenisBulu). Buat objek `Kucing` dan panggil metode `suara()`.
- [ ] **Latihan 2.2 (Encapsulation):** Buat class `RekeningBank` dengan properti `saldo` yang diproteksi (private). Implementasikan metode `setor` dan `tarik`. Lakukan transaksi melalui objek.
- [ ] **Latihan 2.3 (Polymorphism/Method Overriding):** Buat class `BangunDatar` (hitungLuas). Buat class turunan `Persegi` dan `Segitiga` yang meng-override `hitungLuas`.
- [ ] **Latihan 2.4 (Abstraction):** Buat abstract class `Bentuk` dengan metode abstrak `hitungLuas()`. Buat class `Lingkaran` sebagai turunan dan implementasikan metode tersebut.
